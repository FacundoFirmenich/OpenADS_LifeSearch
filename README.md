## Overview

**OpenADS_LifeSearch** represents a paradigm shift in machine-driven bibliometrics, science policy extraction, and hypothesis generation. Fully aligned with Open Source and Open Science principles, this repository hosts two fully autonomous, zero-dependency (CLI interactive) python architectures designed to ingest, process, and map the epistemological frontiers of Astrobiology and Planetary Science.

Bypassing fragile web frameworks, these tools operate as pure OOP "one-shot" scripts ready for deep execution in local terminals, Jupyter Notebooks, or Google Colab environments.

## 🛠 Framework Components

### 1. Open ADS Complexity Toolkit (`open_ads_complexity_toolkit.py`)
A mathematically rigorous engine bridging the [NASA Astrophysics Data System (ADS) API](https://ui.adsabs.harvard.edu/) with Spectral Graph Theory and Bayesian probability.

* **Ramanujan-Proxy Topology:** Constructs dynamic adjacency matrices from high-density keywords, extracting the underlying Eigenvector Centrality of research gravity wells.
* **Epistemic Void Detection:** Quantifies Pointwise Mutual Information (PMI) across thousands of abstracts to automatically flag missing links, synergistic paradigms, and orthogonal boundaries.
* **On-Demand Corporative Output:** Seamlessly generates high-resolution top-tier visual plotting (Matplotlib/Seaborn) and autonomous Markdown diagnostic reports.

### 2. Open Decadal NLP Toolkit (`open_decadal_nlp_toolkit.py`)
A heuristic OCR and Natural Language Processing parser built to aggressively digest monumental policy documents—specifically optimized for the *Planetary Science and Astrobiology Decadal Survey (2023–2032)*.

* **Semantic Stratigraphy:** Maps lexical density across hundreds of pages, isolating priority science queries, 'forkable' hypothesis concepts, and funding targets without human bias.
* **Machine-Driven Exegesis:** Extracts targeted parameters autonomously (e.g., prevalence cross-sections between Enceladus, Europa, Mars, Titan) and constructs density histograms for strategic science policy validation.

## ⚙️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/FacundoFirmenich/OpenADS_LifeSearch.git
   cd OpenADS_LifeSearch
   ```

2. **Install core mathematical dependencies:**
   ```bash
   pip install ads networkx pandas numpy matplotlib seaborn pdfplumber
   ```

3. **Configure your NASA ADS Token:**
   * Acquire a free API token from [NASA ADS Settings](https://ui.adsabs.harvard.edu/user/settings/token).
   * The toolkit allows you to input your token directly through the CLI interface, or you can export it logically:
   ```bash
   export ADS_DEV_KEY="your_api_token_here"
   ```

+++

## 🚀 Usage 

Launch the interactive Command Line Interfaces directly. Follow the dynamic on-screen numerical menus to configure paths, execute heuristic extraction loops, and plot results.

```bash
# To run the ADS Network Centrality Toolkit
python open_ads_complexity_toolkit.py

# To run the Decadal Survey Deep Parser
python open_decadal_nlp_toolkit.py
```
