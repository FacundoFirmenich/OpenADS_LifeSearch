# Historical command-line prototypes

These files are retained for provenance. They are not the canonical P02
analysis and must not be used to support the paper's scientific claims.

- `open_ads_complexity_toolkit.py` is an exploratory ADS/network interface.
- `open_decadal_nlp_toolkit.py` is an exploratory text-analysis interface.
- `open_astro_priority_toolkit.py` contains fixed illustrative inputs and a
  stochastic priority calculation. Its output is not observational evidence.

The former embedded ADS credential has been removed from the current branch.
The canonical, deterministic analysis is `src/openads_reanalysis.py`.
