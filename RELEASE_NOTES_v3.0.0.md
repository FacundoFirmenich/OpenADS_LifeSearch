# OpenADS_LifeSearch v3.0.0

This release turns the repository into a reproducible research object.

## Added

- deterministic canonical record-level reanalysis;
- exact six-target permutation inference;
- aggregate results, figures, receipts, hashes, and tests;
- acquisition script with environment-only authentication;
- scientific audit, data-governance boundary, and claim ledger;
- non-manuscript v4.5 research package, provenance, offline graphs, and diagnostics.

## Corrected

- Mars's raw and reciprocal-authorship shares;
- interpretation of reciprocal team-size weighting;
- rank claims across scale, trajectory, and citation reception;
- citation-normalization label and scope;
- treatment of multi-target papers;
- active-code credential handling.

## Removed from the active scientific surface

- researcher-FTE and productivity claims;
- simulated precision, recall, agreement, and Decadal evidence;
- incompatible Gamma-Poisson inference;
- unsupported budget, thermodynamic-power, and detection-probability claims;
- toy stochastic priority code (retained only under `archive/legacy_cli`).

## Deliberately not published in the repository

- manuscript and supplementary PDF/LaTeX files;
- record-level ADS data and derivatives whose redistribution is restricted.
